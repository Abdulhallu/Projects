## TeleHealth Trends Dashboard (Power BI – Healthcare Analytics)

This Power BI dashboard explores telehealth visit patterns using synthetic healthcare data. It focuses on patient demographics, appointment trends, satisfaction scores, and department-level insights.

### 📊 Dashboard Highlights:
- **KPI Summary**: Total visits, gender split, average wait time, satisfaction score
- **Time-Based Insights**: Daily, monthly, quarterly, and yearly trends
- **Demographics**: Age, gender, and race breakdowns
- **Operational Views**: Wait time distribution, visit timing (AM/PM), referral departments
- **Satisfaction Analysis**: Score patterns and department alignment
