# Projects

This repository contains academic and practical projects related to Business Analytics, Forecasting, Machine Learning, and Data Science.

---

## 📊 Power BI Dashboards

Explore interactive dashboards that apply real-world data storytelling and business-focused analysis using DAX, Power Query, and advanced visualization.

### 1. [Global Sales Dashboard](./PowerBI_GlobalSales)
Analyzes revenue, delivery, return orders, and customer segmentation across time and regions using Global Superstore data.

### 2. [Customer Retention & Risk Analysis](./CustomerRetentionPowerBI)
Identifies churn drivers, high-risk customers, and contract behaviors using predictive visuals and interactive slicers.

### 3. [TeleHealth Trends Dashboard](./TeleHealthTrends)
Breaks down patient demographics, satisfaction scores, wait times, and department referral patterns in a synthetic healthcare dataset.
